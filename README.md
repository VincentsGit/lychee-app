# lychee (A simple Blog Website)

## About

This is a simple react + flask application I have created for my girlfriend.

It is a blog that will allow her to write and create blog posts for anyone on the internet to read.

The final website will be ran on my Raspberry Pi.

I will be using this as an opportunity to improve my developer workflow using Docker and explore full stack development.

## How to run

To run the application, simply run the following commands in the correct working directory in order:

1. `docker compose build`
2. `docker compose up`
